# Examples

Runnable `.kt` programs that exercise the interpreter through the real
`klio` binary. The set grows monotonically — every new language feature
lands with at least one example here demonstrating it end-to-end.

Run any program with:

```sh
cargo run -p klio-cli -- run examples/<name>.kt
```

## Index

| File            | Feature surface exercised                                                |
| --------------- | ------------------------------------------------------------------------ |
| `hello.kt`      | Smallest end-to-end slice: `println(1 + 1)`.                             |
| `showcase.kt`   | Everything currently wired through the interpreter: literals, full arithmetic/comparison/logical precedence, unary + prefix/postfix `++`/`--`, `val`/`var` with compound assignment, `if` as an expression, string templates, `while` and `for` loops with `break`/`continue`, user-defined functions and recursion, `println`. |
| `functions.kt`  | Focused tour of user functions: default args, recursion, mutual recursion, top-level properties, and a local function closing over its enclosing scope. |
| `stdlib_taste.kt` | First slice of native Rust stdlib intrinsics: `kotlin.math.*` (abs/min/max/sqrt/pow, `PI`/`E`), `kotlin.String.*` members (length, uppercase, lowercase, isEmpty/isNotEmpty), `kotlin.Int.*` conversions, all dispatched through `klio-stdlib::implementation`. |
| `m6b_taste.kt` | M6b additions: `throw` / `try` / `catch` / `finally` with the standard exception hierarchy; lambdas with explicit params and implicit `it`; scoping fns (`let`, `also`, `apply`, `run`, `takeIf`, `takeUnless`, `with`) with correct `it` / `this` receiver binding; String indexing; the expanded numeric / string / char / math intrinsic surface. Passes parity against `kotlinc-native 2.3.21`. |
| `classes.kt`    | M10 classes & objects: plain class with primary-ctor properties and methods, `data class` with `equals` / `toString` / `copy` / `componentN`, `companion object`, standalone `object` singleton, user `operator fun compareTo` used by `sortedWith` and natural-order `sorted()`. Passes parity. |
| `enums.kt`      | M11 enum classes: bare entries, entries with ctor args, member functions, per-entry method overrides via `abstract fun`, `name` / `ordinal`, `Color.values()` / `entries` / `valueOf(...)`, ordinal-based comparison, iteration. Passes parity. |
| `sealed_when.kt` | M12 `when` expression + `sealed class` + `is` / `!is`: `when (node) is JsonNum / JsonStr / …` over a sealed hierarchy with smart-cast member access, plus subject-bound `when` with `,`, `in range`, `!in range`, and `else` patterns. Passes parity. |
| `interfaces.kt` | M14 interfaces: `interface` declarations with abstract methods and abstract properties, default-method bodies, default-method calling abstract members, multiple interfaces on a single class, interface-extending-interface, marker (empty) interfaces, `class Sub : Parent(), Iface1, Iface2` mixing a concrete parent with interfaces, and `is`-checks against interface types. Passes parity. |
| `inheritance.kt` | M13 inheritance: `open class` / `open fun` / `override`, super-constructor invocation (`: Parent(args)`), `super.method()` calls, parent-init-runs-before-child ordering, inherited property access, polymorphic dispatch over a `List<Shape>`. Passes parity. |
| `delegates.kt`  | M15 custom getters/setters + property delegates: `get() = …` and `get() { … }`, `set(value) { field = … }` with backing-field tracking, `by lazy { … }`, `Delegates.observable(initial) { _, old, new -> … }`, `Delegates.notNull<T>()` (with the `IllegalStateException` on early read), and a user-written delegate class with `operator fun getValue` / `setValue`. Passes parity. |
| `abstract_inner.kt` | M16 abstract classes, secondary constructors, and inner classes: `abstract class` with `abstract val` and `abstract fun` overridden by concrete subclasses, polymorphic dispatch across the hierarchy, and an `inner class` whose method reads outer-instance state. Passes parity. |
| `anon_local.kt` | M17 anonymous object expressions and local classes: `object { … }` and `object : Iface { … }` assigned to a `val` and returned from a function (closure-capturing the enclosing scope), plus a `class` declared inside `fun main` whose method reads a captured local. Passes parity. |
| `collections.kt` | M9 collections + ops: `listOf` / `mutableListOf` / `setOf` / `mutableSetOf` / `mapOf` / `mutableMapOf`; `to` infix → `Pair`; higher-order ops `map` / `filter` / `forEach` / `fold` / `reduce` / `any` / `all` / `count` / `find` / `sumOf`; for-loop iteration over List / Set / Map (yielding `Map.Entry` with `.key` / `.value`); indexing on List + Map. Passes parity. |
| `stdlib_broad.kt` | M18 broad stdlib surface: indexed list ops (`mapIndexed`/`forEachIndexed`), `firstOrNull`/`lastOrNull`/`distinct`/`containsAll`, `groupBy`, map higher-order ops (`filterKeys`/`mapValues`/`getOrElse`), string `substringAfterLast`/`lines`/`padStart`/`trim`, char `code`/`digitToInt`/`Int.toChar`, range `toList`/`sum`/`downTo step`, top-level `repeat`/`require` with caught failure. Passes parity. |
| `string_ordering.kt` | M22 UTF-16 string ordering: `String.compareTo` and the `<` / `>` / `<=` / `>=` operators compare code-unit by code-unit, so supplementary characters (e.g. `😀` 😀) sort before private-use BMP code points where a UTF-8 byte comparison would disagree. Also exercises `sortedBy { it }` over a mixed BMP / supplementary list. Passes parity. |
| `char_unicode.kt` | M22 Char Unicode categories: `isLetter` / `isDigit` / `isUpperCase` / `isLowerCase` / `isWhitespace` driven by Unicode general categories matching `kotlinc-native 2.3.21` (rather than Rust's `char::is_*`). Covers non-ASCII letters, the Arabic-Indic decimal digit class, ASCII control whitespace (``), NBSP, and the Other_Uppercase / Other_Lowercase contributory ranges (Roman numerals, circled letters, modifier letters, the feminine ordinal). Passes parity. |
| `scoping_fns_top_level.kt` | M22 top-level scoping fns: bare `run { ... }` (no-receiver form) returning a value, returning `Unit`, nested `run`s composing through a `val` initializer, and `with(receiver) { ... }` for contrast. Passes parity. |
| `accessor_return_type.kt` | M22 accessor return-type annotations: `val area: Int get(): Int = …` and `val label: String get(): String = …` — the type checker enforces the explicit accessor return type against the property's declared type and rejects mismatches with T0018. Passes parity. |
| `function_types.kt` | M22 function types as type annotations: `val f: (Int) -> Int = { x -> x * 2 }`, multi-parameter forms `(Int, Int) -> Int`, function-returning-function `(Int) -> (Int) -> Int` (right-associative), function-typed parameters, nullable function types `((Int) -> Int)?`, and a function returning a function. Lambdas assigned to these annotations dispatch through the existing invocation path. Passes parity. |
| `plain_class_tostring.kt` | M22 default `Any.toString` for plain classes: renders as `ClassName@<hex>` with a per-instance identity, asserted structurally (prefix / `@` / hex tail / per-instance distinctness) so parity holds byte-identical despite the hex value differing between kotlinc-native (heap address) and klio (monotonic counter). Passes parity. |
| `anon_object_tostring.kt` | M22 default `toString` for anonymous-object instances: structural assertions about the synthesized name plus `@<hex>` form, plus an explicit `override fun toString` case. kotlinc-native synthesizes `main$<name>$<n>`; klio uses `<no name provided>@<hex>`. Passes parity. |
| `enum_entries_interface.kt` | M22 `EnumEntries` interface: `EnumName.entries` reports `true` for both `is List<*>` and `is EnumEntries<*>`, while a plain `listOf(...)` reports `false` for the latter. All existing List ops (`size`, indexing, iteration, `map`) continue to work on the entries. Passes parity. |
| `delegated_inheritance.kt` | M22 inherited delegated properties: a `val ... by lazy { ... }` declared on an `open class` resolves through the parent's delegate when accessed via a subclass instance or an upcast `Parent` reference. Passes parity. |
| `interface_companion_state.kt` | M22 interface companion-object state: `companion object { var n }` on an `interface` holds shared mutable state; an interface default method reaches the companion's `var` by simple name, and writes from every implementor land on the same companion instance. Passes parity. |
| `qualified_this.kt` | M22 qualified `this@OuterClass`: from inside an `inner class` method, from inside a method of a `class` declared in a method body, and from inside a method of `OuterClass` itself. The label resolves to the enclosing class's instance via the receiver's outer chain plus the leaf class's own type name (and its ancestor names). An unknown label produces a runtime diagnostic. Passes parity. |
| `enum_companion.kt` | M22 enum companion objects: a companion on an `enum class` resolves `entries` and the enum's own entries (`LOW`, `MID`, `HIGH`) by simple name from inside the companion's method bodies, matching kotlinc-native's bare-name resolution. Passes parity. |
| `sealed_when_exhaustive.kt` | M23 sealed-`when` exhaustiveness: typeck (T0019) rejects a `when` over a sealed-class subject that omits a concrete subclass when there is no `else` branch. This example covers every subclass explicitly so typeck stays silent and runtime never hits `NoWhenBranchMatchedException`. Passes parity. |
| `definite_assignment.kt` | M23 definite-assignment: typeck (T0020) rejects reads of a `var` (or a `val`) declared without an initializer before every reaching path has written to it. Demonstrates the positive case — both arms of an `if`/`else` assign before the read — across `val` for a constant choice and `var` for an accumulator. Passes parity. |
| `smart_cast_field.kt` | M23 smart-cast narrowing for `val` instance fields: after `if (w.shape is Circle)` the type checker narrows `w.shape` to `Circle` inside the branch, so `w.shape.radius` resolves through `Circle`'s member table without an explicit cast. Passes parity. |
| `extension_functions.kt` | M23 user extension functions: parser accepts `fun T.foo(...)`, the interpreter dispatches at the call site by walking the receiver's class chain (so an extension on a parent class applies to subclasses), and the type checker resolves `recv.ext()` through a per-receiver extension table with the same first-fit overload picker used for regular calls. Passes parity. |
| `extension_property.kt` | Phase H extension properties: `val T.foo: U get() = ...` and `var T.foo: U` with `set(value)`. No backing field; the getter/setter run with `this` bound to the receiver. Member properties win over extension properties when both apply. Diagnostics T0040/T0041/T0042 reject initializers, `by`-delegates, and missing accessors. |
| `arrays.kt` | M24 arrays + index-assign: `Array<T>`, `IntArray` and the other primitive variants, `Array(n) { i -> init }` / `IntArray(n) { init }`, `arrayOf`/`arrayOfNulls`, `.size` / `.indices` / `.lastIndex` / `.toList()`, `for` iteration, and `xs[i] = v` plus compound `+=`/`*=` writes on both Array and `MutableList`. Output is iterative because the default array `toString` (`[I@<hash>`) is not parity-friendly. Passes parity. |
| `regex.kt` | M25 `kotlin.text.Regex`: pattern construction, `find` / `findAll` / `containsMatchIn` / `matches` / `matchEntire`, capture groups via `groupValues` and `groups[i]?.value` / `.range`, `String.split(Regex)` and `String.replace(Regex, replacement)`, `Regex.escape` (Kotlin `\Q...\E` form) and `Regex.fromLiteral`. `for (m in regex.findAll(text))` iterates a `Sequence<MatchResult>`. Passes parity. |
| `string_builder.kt` | M25 `kotlin.text.StringBuilder`: `append` overloads, `appendLine`, `length`, `isNotEmpty`, `insert`, `reverse`. Passes parity. |
| `sam_conversion.kt` | M26 SAM conversion: `fun interface` declares a single-abstract-method interface; the `Interface { lambda }` constructor-call form synthesizes an instance whose abstract method dispatches through the lambda. Passes parity. |
| `reflection_lite.kt` | M26 reflection-lite: `Foo::class` → KClass with `simpleName` / `qualifiedName`; `Foo::propName` → KProperty1 with `.name` and `.get(receiver)`; `::Foo` / `::topFn` resolve to a class reference / function reference callable directly. Passes parity. |
| `numeric_fidelity.kt` | M27 numeric type fidelity: distinct runtime variants for `Int` / `Long` / `Short` / `Byte` / `Float` / `Double`; 32-bit wraparound for `Int` and 64-bit for `Long`; conversion methods (`toInt` / `toLong` / `toShort` / `toByte` / `toFloat` / `toDouble`) that materialise the right variant with Kotlin spec semantics; mixed-type arithmetic following the Kotlin promotion rules; `LongRange` iteration yielding `Long`-typed values. Passes parity. |
| `variance.kt` | M28 declaration-site variance: `class Producer<out T>` and `class Sink<in T>` with the corresponding `Producer<Int>` → `Producer<Any>` upcast and `Sink<Any>` → `Sink<Int>` downcast that the variance rules permit. T0024 fires declaration-side when `out`/`in` are used in the wrong position. |
| `bounds.kt` | M28 upper bounds + multi-bound `where` clause: `fun <T : Comparable<T>> maxOfPair(a, b)` selects the greater value via the operator overload, and `fun <T> describe(t: T) where T : Named, T : Sized` accepts only types implementing both interfaces. |
| `reified.kt` | M28 reified type parameters on `inline fun`: `inline fun <reified T> isAnInstance(value: Any): Boolean = value is T` consults a per-call reified-type frame at the `is`-check site, matching the type the caller wrote at `<...>`. |
| `inline_modifiers.kt` | M28 `inline` + `crossinline` parameter modifier: a `crossinline` lambda parameter is only allowed on an `inline fun` (T0026 fires on misuse); the lambda body runs inline at every call site. |
| `when_binding.kt` | M29 / Phase B `when (val v = subject)` subject binding: the bound `v` is in scope inside every branch body and is smart-castable like an ordinary local `val`. The example dispatches over `Int` / `String` / `Double` and computes a branch-specific projection of `v` (`v * v`, `v.length`, etc.). |
| `as_cast.kt` | M29 / Phase C `as` / `as?` cast expressions: unsafe `as` returns the receiver typed as the target when the runtime check succeeds and throws `kotlin.ClassCastException` otherwise; safe `as?` returns `null` instead of throwing. Left-associative chaining (`v as Any as String`) is exercised end-to-end. |
| `anon_fun.kt` | M29 / Phase C anonymous-function expressions: `fun(x: Int): Int = x + 1` and the block form participate in higher-order calls just like lambdas. `return` inside the body is a local return out of the anonymous function. |
| `infix_calls.kt` | M29 / Phase D generalized infix function calls: any `infix fun A.name(b: B)` (member or extension) is callable as `a name b`. Top-level extension form chains left-associatively. T0029 fires when an infix call site resolves to a function declared without the `infix` modifier. |
| `labeled_jumps.kt` | M29 / Phase D labeled jumps: `label@ for(...) { ... }` binds a loop name that `break@label` / `continue@label` target; `label@ run { ... }` binds a name that `return@label value` targets, returning out of the labeled scope. T0030 fires when the label name is not lexically bound. |
| `visibility.kt` | M29 / Phase E visibility enforcement: `private` / `protected` / `internal` / `public` modifiers on class members. `protected` is reachable through `this` from a subclass body; `private` only from the declaring class. `internal` behaves as `public` until module boundaries are modeled. T0031 fires on out-of-scope member or constructor access; T0032 on a `private` top-level reference from another file. |
| `const_val.kt` | M30 / Phase F `const val` properties: compile-time constants at top level and inside an `object` (including a `companion object`). Initializers may reference other `const val` names; string templates over `const val` are themselves const. T0033 fires on `const val` declared inside a class body; T0034 on a non-constant initializer, a non-primitive/non-String type, or a `const val` with a delegate / custom accessor. |
| `value_class.kt` | M30 / Phase F `value class` (single-property wrappers): a `value class` declares exactly one `val` primary-constructor property, no body backing fields, no init blocks, and no non-interface supertypes. Construction and field access route through the existing instance machinery; the deprecated alias `inline class` warns and is treated as `value class`. T0035 covers the shape constraints. |
| `typealias.kt` | M30 / Phase G `typealias` declarations: top-level aliases that desugar transparently at use sites. Covers a non-generic alias (`IntList = List<Int>`), a parameterized alias substituted at the use site (`Pair2<A> = Pair<A, A>`), and an alias to a function type (`Pred<T> = (T) -> Boolean`). T0038 fires on a recursive alias; T0039 on a `typealias` declared inside a class or function body. |
| `inheritance_delegation.kt` | M30 / Phase I inheritance delegation: `class C(d: I) : I by d` forwards every member of interface `I` not explicitly overridden in `C` to the captured delegate. An explicit override on `C` wins over the synthesized forwarder, and `equals` / `hashCode` / `toString` are intentionally not delegated. T0043 fires when the named supertype is not an interface; T0044 when the delegate expression's static type is not a subtype of the interface. |
| `annotation_class.kt` | M30 / Phase F `annotation class`: annotation types declare only primary-constructor `val` parameters of primitive / `String` / `KClass` / enum / nested-annotation / `Array` type. Bodies are empty (a bare companion object is permitted). T0036 fires on body declarations / illegal modifiers; T0037 on a parameter whose type is not a permitted annotation-parameter type. |
| `data_object.kt` | Phase J `data object` declarations: special object singleton with auto-generated `toString` (the simple class name) and identity-based `equals` / `hashCode`. No `copy`, no `componentN`. T0045 fires when the source overrides `equals` or `hashCode`. |
| `vararg_spread.kt` | Phase J `vararg` call-site spread `*arr` mixed with positional arguments. The interpreter splices the array elements into the vararg slot in source order. T0047 fires when `*` is supplied to a non-vararg parameter. |
| `tailrec.kt` | Phase K `tailrec` modifier: the interpreter trampolines every tail-position self-call so deeply recursive accumulator-style functions don't grow the host stack. `factorial(20L)` with a default-arg accumulator, a `when`-driven loop, and a 100 000-deep counter all run to completion. Typeck emits T0048 for a self-call left in non-tail position and T0049 when `tailrec` is declared but no tail call is present. |

All examples are gated by `cargo test -p klio-parity --test parity` — every entry here produces byte-identical output to `kotlinc-native`. New examples must include a passing parity check before they ship.

When you add support for new functionality (strings, `val`/`var`, control
flow, classes, lambdas, …), add a new example here and extend the table.
Each example should print something deterministic so a future end-to-end
test harness can assert against its output.
